# ADR 0040: 面接の予定は社内に留め、結論の期限を応募が持つ

- 状態: 採用
- 決定日: 2026-08-02

この文書は日本語版を正本とする。

## 背景

P8 の対象範囲は「面談・面接予定」「期限」「監査記録」を含む。

ステージ（ADR 0038）は「いまどこまで進んだか」を表す。
いつ会うのか、いつまでに決めるのかは持っていない。

期限がないと、応募は返事のないまま放置される。
放置は、応募者から見れば不採用と区別がつかない。

応募者へ予定を伝える手段はまだない（P9 で扱う）。

## 決定

- 面接の予定（`interview_schedules`）を応募へ従属させる
- 開始日時を必須とし、所要時間・場所・備考を任意とする
- **過ぎた日時での作成を拒否する**（作成時のみ）
- 取消は状態を変えるだけとし、行は消さない
- 予定の作成と取消を `job_application_events` へ記録する
- 応募へ結論の期限（`decide_by`）を持たせる。**任意**とする
- 過ぎた日付の期限は設定できない
- 期限を過ぎた応募（`overdue`）が分かるようにする。取り消された応募は数えない
- **予定も期限も応募者へは見せない**。求職者側の画面・エクスポートに現れない
- 読み書きできるのは、その組織の所属者だけとする

## 理由

過ぎた日時を拒否するのは、過ぎた日時の予定が予定ではないためである。
一方、作成の後に時間が過ぎるのは当然であり、更新の時点では確かめない。
確かめると、終わった予定の備考を直せなくなる。

取消で行を消さないのは、予定があったことが選考の経緯だからである。
ステージの変更（ADR 0038）や応募の取消（ADR 0035）と同じ扱いにそろえた。

記録を同じ表へ置くのは、「その応募に何が起きたか」を 1 か所で読めるようにするためである。

期限を任意にするのは、すべての応募に締め切りがあるわけではないためである。
必須にすると、意味のない日付が入る。

期限を過ぎた応募から取消済みを外すのは、返事を待っているのが応募者だからである。
取り消した応募には、待っている相手がいない。

予定と期限を応募者に見せないのは、伝える手段がないためである。
画面に出しても、応募者はそれを見に来ない。
中途半端に見せると、「予定が入ったのに連絡がない」という状態を作る。
伝える経路（P9）ができた時点で、何をどう伝えるかを決める。

## 採用しない代替案

| 代替案 | 採用しない理由 |
| --- | --- |
| 更新時も過去日時を拒否する | 終わった予定の備考を直せなくなる |
| 取消で行を消す | 予定があったことが経緯として残らない |
| 予定の記録を別の表に持つ | 同じ応募の履歴が分かれ、突き合わせが要る |
| 期限を必須にする | 意味のない日付が入る |
| 期限切れに取消済みを含める | 待っている相手がいない応募が並ぶ |
| 予定を応募者にも見せる | 伝える手段がなく、「予定が入ったのに連絡がない」状態を作る |
| カレンダーと連携する | 外部サービスへの依存が増える。P8 の非目標である |

## 影響

- 応募者への予定の共有・調整は行っていない。P9（通知・メッセージ）で扱う
- 予定の重複（同じ時間に複数の面接）は検出していない
- 期限が近いことの通知はない
- 予定の保存期間は未定（P10）
- 面接の予定は応募に従属する。求人単位・担当者単位で見る画面はない
