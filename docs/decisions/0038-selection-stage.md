# ADR 0038: 選考ステージは応募が持ち、確定は管理者だけができる

- 状態: 採用
- 決定日: 2026-08-02

この文書は日本語版を正本とする。

## 背景

P8 の完了条件は「応募を選考ステージ間で移動できる」
「ステージ変更が履歴として残る」「権限のない担当者は選考を操作できない」を含む。

応募は `submitted` / `withdrawn` の 2 つしか状態を持たない（ADR 0034）。
これは「応募が生きているか」であり、選考がどこまで進んだかではない。

求人の審査（ADR 0017）では、申請は所属者、承認と差し戻しは管理者と分けた。
選考も同じ性質を持つ。次の面接へ進めることと、不採用を確定することは重さが違う。

応募の記録（ADR 0037）はすでに `job_application_events` にある。

## 決定

- 選考ステージ（`job_applications.stage`）を応募が持つ。**`status` とは別の列とする**
- 値は `screening` / `interviewing` / `offered` / `hired` / `rejected` / `declined`
- 既定は `screening`
- 遷移できる先を状態ごとに定める（`STAGE_TRANSITIONS`）。任意の状態へは飛べない
- `hired` / `rejected` / `declined` は終わりとし、そこからは動かせない
- 取り消された応募（`withdrawn`）のステージは動かせない
- **面接へ進める操作は所属者、`offered` / `hired` / `rejected` / `declined` は管理者だけ**
- 変更は `job_application_events` へ記録する。**表を分けない**
- 記録には変更前後のステージと、変更した利用者を残す
- 経路は応募を見る経路とは分けて置く

## 理由

`status` と分けるのは、2 つが別のことを表すためである。
「応募者が取り消した」と「企業が不採用にした」は、同じ列に入れると区別できない。
取り消された応募が `rejected` になっていると、誰の判断だったかが読めない。

遷移を定めるのは、飛べる状態を作ると履歴が意味を失うためである。
書類選考からいきなり `hired` にできると、面接をしたのかどうかが記録から読めない。

終わりのステージから動かせないのは、確定を巻き戻す操作が
「なかったことにする」になるためである。
必要になった場合は、巻き戻しではなく別の応募として扱う。

取り消された応募を動かせないのは、応募者がもう選考を望んでいないためである。
その状態で内定を出しても、相手には届かない。

確定を管理者に限るのは、採否がその後の関係を決める操作であるためである。
求人の審査（ADR 0017）で申請と承認を分けたのと同じ理由による。
面接へ進めることは、選考を続けるという意思表示にすぎない。

記録を同じ表へ置くのは、「その応募に何が起きたか」を 2 か所へ分けると
読むときに突き合わせが要るためである。
応募・取消・ステージの変更は、すべて同じ応募の履歴である。

経路を分けるのは、見る権限がそのまま選考を動かす権限になることを避けるためである。

## 採用しない代替案

| 代替案 | 採用しない理由 |
| --- | --- |
| `status` へステージを混ぜる | 応募者の取消と企業の不採用が区別できない |
| 任意のステージへ飛べるようにする | 面接をしたかどうかが履歴から読めない |
| 確定を巻き戻せるようにする | 「なかったことにする」操作になる |
| 確定も所属者に許す | 採否がその後の関係を決める。求人の承認と同じ重さである |
| ステージの記録を別の表に持つ | 同じ応募の履歴が 2 か所へ分かれ、突き合わせが要る |
| 組織ごとにステージを設定できるようにする | 語彙が組織ごとに変わり、記録の意味が読めなくなる |
| 取り消された応募も動かせるようにする | 応募者が望んでいない選考が進む |

## 影響

- 求職者側の画面には、まだステージを出していない。
  どこまで見せるかは、通知（P9）とあわせて決める
- 不採用の理由は記録していない。応募者へ伝えるかどうかを含めて、別に判断する
- 評価・コメントは P8-T2、面接の予定・期限は P8-T3 で扱う
- 辞退（`declined`）は企業側の操作として記録する。
  求職者が自分で辞退を伝える経路はない。取消（ADR 0035）とは別の意味である
- `job_application_events` の保存期間は未定（P10）
