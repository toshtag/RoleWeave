# ADR 0009: パスワード再設定を使い切りの署名付き token で行う

- 状態: 採用
- 決定日: 2026-08-01

この文書は日本語版を正本とする。

## 背景

ADR 0005 で、メールアドレスを識別子にする理由のひとつとして
「パスワード再設定と本人確認が同じ宛先を使う」ことを挙げた。その経路をここで決める。

再設定は、パスワードを知らない相手がアカウントへ入る唯一の正規の入口になる。
リンクを持つ者が新しいパスワードを決められるため、
有効期限、使い切り、再設定後の既存セッションの扱いを先に決める必要がある。

ADR 0008 では、確認メールの token を `generates_token_for` で作り、
データベースへ保存しない方式を採った。同じ方式を再設定へも使えるかを検討する。

## 決定

- 再設定の依頼は、メールアドレスだけを受け取る
- 依頼の応答は、登録の有無に関わらず同じ画面を出す
- token は `generates_token_for :password_reset` で作り、`password_salt` を含める
- 有効期限は 30 分とする
- 再設定が成功したら、そのアカウントのセッションをすべて破棄する
- 再設定後は自動でログインせず、ログイン画面へ送る
- 失敗の理由（壊れている、期限切れ、使用済み）を画面で区別しない
- 再設定メールにパスワードそのものを書かない
- 再設定されたことを知らせる通知メールは、この ADR では扱わない

## 理由

依頼の応答を登録の有無で変えないのは、区別するとこの画面が
登録済みのメールアドレスを調べる道具になるためである。

ADR 0008 では、登録画面について同じ寄せ方を採らなかった。
理由が違う。登録画面では、打ち間違いで別のアドレスを入れた利用者が
「メールが届かない理由」を自分で切り分けられなくなる。
再設定の依頼では、利用者はどちらの場合も「メールを待つ」だけであり、
区別しなくても次の行動は変わらない。
費用が違うため、同じ判断にはならない。

token へ `password_salt` を含めるのは、パスワードを変えた時点で
発行済みのリンクを使えなくするためである。
使い切りの印をデータベースへ持たなくても、「1 度使ったら無効」を満たせる。
印を持つ方式では、印を消す処理が失敗したときに token が生き残る。

有効期限を 30 分にするのは、確認リンクより危険が大きいためである。
確認リンクは「そのアドレスが本人のものか」を確かめるだけだが、
再設定リンクはアカウントそのものを渡す。
リンクが有効な時間は、そのまま危険な時間になる。

セッションをすべて破棄するのは、変更の理由が乗っ取りだった場合に、
残したままでは相手が居座り続けるためである。
利用者はパスワードを変えたのだから、相手は締め出されたと考える。

自動でログインしないのは、新しいパスワードで入れることを
利用者自身がその場で確かめられる状態にするためである。
自動でログインすると、控え間違いに気付くのが次回のログイン時になる。

失敗の理由を区別しないのは、区別すると token を試す手がかりになるためである。

## 採用しない代替案

| 代替案 | 採用しない理由 |
| --- | --- |
| token をデータベースへ保存し、使用済みの印を持つ | 印を消す処理が失敗すると token が生き残る |
| `password_salt` を含めない | 1 度使った後もリンクが有効なままになる |
| 有効期限を確認リンクと同じ 24 時間にする | アカウントを渡すリンクが 1 日有効になる |
| 依頼の応答を登録の有無で変える | 登録済みのメールアドレスを調べる道具になる |
| 再設定後に自動でログインする | 控え間違いに気付くのが次回のログイン時になる |
| 既存のセッションを残す | 乗っ取られていた場合、相手が居座り続ける |
| 新しいパスワードをメールで送る | 平文のパスワードが保存も転送もされる媒体に残る |

## 影響

- パスワードを変えると、その利用者は全端末でログアウトされる。
  再設定した端末でも、あらためてログインする必要がある
- 再設定されたことを知らせる通知メールを送っていない。
  身に覚えのない再設定を利用者が気付けるようにする手段は、別途判断する
- 依頼の受付に回数の制限を設けていない。
  同じアドレスへ何通でもメールを送れる状態が残る。
  試行回数の制限を入れるタスクで、この経路も対象に含める
- ログイン中のパスワード変更は、この ADR では扱わない。
  現在のパスワードの確認を伴うため、条件が異なる
