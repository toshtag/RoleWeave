# 企業の担当者として使う

この文書は日本語版を正本とする。

デモデータを入れた状態を前提とする。
`owner@example.invalid`（管理者）と `member@example.invalid`（一般の所属者）で、
できることの違いを試せる。

## 役割の違い

| 操作 | 管理者 | 一般の所属者 |
| --- | --- | --- |
| 求人を作る・編集する | できる | できる |
| 求人の公開を申請する | できる | できる |
| **求人を承認・差し戻し・停止する** | できる | **できない** |
| 応募を見る | できる | できる |
| 面接へ進める | できる | できる |
| **内定・採用・不採用・辞退を確定する** | できる | **できない** |
| 評価を書く | できる | できる |
| 担当者を決める | できる | できる |
| 人を招待する・役割を変える | できる | **できない** |

できない操作は、画面に出ないだけでなく**経路そのものが 404 を返す**。
権限がないことと、存在しないことを分けない
（[ADR 0013](../decisions/0013-role-based-authorization.md)）。

## 1. 組織を作る・人を集める

| やりたいこと | 経路 |
| --- | --- |
| 組織を作る | `/ja/organizations/new` |
| 所属する組織を見る | `/ja/organizations` |
| 所属者と履歴を見る | `/ja/organizations/:id/memberships` |
| 人を招待する | 所属者の画面から「招待する」 |

組織を作った人が最初の管理者になる。
**組織の最後の管理者は、役割を変えられない**（誰も操作できない組織を作らないため）。

## 2. 求人を出す

| やりたいこと | 経路 |
| --- | --- |
| 求人の一覧を見る | `/ja/organizations/:id/job_postings` |
| 求人を作る | `/ja/organizations/:id/job_postings/new` |
| 公開時の表示を確認する | 求人の一覧から「公開時の表示を見る」 |

求人は次の順に進む（[ADR 0017](../decisions/0017-job-posting-review.md)）。

```
下書き → 申請中 → 公開中 → 停止中 → 申請中 …
              ↘ 差し戻し → 申請中
```

**申請は誰でもできる。承認は管理者だけができる。**
公開中の求人は編集できない。直すには差し戻すか停止する。

## 3. 応募を見る

| やりたいこと | 経路 |
| --- | --- |
| 届いた応募を見る | `/ja/organizations/:id/job_postings/:job_posting_id/applications` |
| 応募の詳細を見る | 応募の一覧から応募者の名前 |
| 応募者の現在のプロフィールを見る | 応募の詳細から（公開範囲が許すときだけ） |

**見えるのは応募時点の写しである。**
応募者が後からプロフィールを変えても、この内容は変わらない。

応募の一覧を開いたこと、プロフィールを開いたこと、添付を取得したことは、
すべて記録に残る（[ADR 0047](../decisions/0047-access-audit-log.md)）。

## 4. 選考を進める

| やりたいこと | 経路 |
| --- | --- |
| 選考の段階を進める | 応募の詳細のボタン |
| 評価とコメントを書く | 応募の詳細の「社内の評価」 |
| 担当者を決める | 応募の詳細の「担当者」 |
| 面接の予定を入れる | 応募の詳細の「面接の予定」 |
| 結論の期限を決める | 応募の詳細の「結論を出す期限」 |

段階は `書類選考 → 面接 → 内定 → 採用` と進む。
不採用・辞退はどの段階からでも記録できる（[ADR 0038](../decisions/0038-selection-stage.md)）。

**採用・不採用・辞退は取り消せない。**確定した後は動かせない。

評価・面接の予定・期限は**応募者には見えない**。
面接の予定を入れても応募者へは伝わらない。日程はやり取りで伝える。

## 5. 応募者と連絡する

| やりたいこと | 経路 |
| --- | --- |
| やり取りを見る・送る | 応募の詳細から「やり取りを見る」 |

会話は応募ごとにある。応募を経由しない連絡はできない
（[ADR 0041](../decisions/0041-application-conversation.md)）。

応募が取り消されると、新しいメッセージは送れない。読むことはできる。
