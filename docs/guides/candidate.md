# 求職者として使う

この文書は日本語版を正本とする。

デモデータ（[README](../../README.md) の「デモデータを投入する」）を入れた状態を前提とする。
`candidate@example.invalid` でログインすると、この手順の途中から追える。

URL はすべて `/ja` から始まる（日本語）。英語で見る場合は `/en` に読み替える。

## 1. アカウントを作る

| やりたいこと | 経路 |
| --- | --- |
| アカウントを作る | `/ja/registration/new` |
| ログインする | `/ja/session/new` |
| パスワードを忘れた | `/ja/password_reset/new` |

作成すると確認メールが届く。**確認するまで、応募もプロフィールの作成もできない。**
development では、メールは送信されず `log/development.log` に出力される。

## 2. プロフィールを作る

| やりたいこと | 経路 |
| --- | --- |
| プロフィールを作る・見る | `/ja/profile` |
| 職歴を管理する | `/ja/profile/work_experiences` |
| 学歴を管理する | `/ja/profile/educations` |
| スキルを管理する | `/ja/profile/skills` |
| 希望条件を書く | `/ja/profile/desired_condition/edit` |
| 履歴書・職務経歴書を添付する | `/ja/profile/documents/edit` |

必須は**表示名だけ**である。ほかは後から足せる。

生年月日・性別・顔写真の項目はない。持たないことを決めている
（[ADR 0026](../decisions/0026-candidate-profile.md)）。

## 3. 公開範囲を決める

| やりたいこと | 経路 |
| --- | --- |
| 公開範囲を設定する | `/ja/profile/visibility/edit` |

**既定は「誰にも見せない」である。**設定を変えるまで、企業からは見えない。

| 設定 | 誰に見えるか |
| --- | --- |
| 誰にも見せない | 自分だけ |
| 応募した企業にだけ見せる | 応募中の企業だけ（取り消すと見えなくなる） |
| すべての企業に見せる | いずれかの組織に所属する利用者 |

希望年収と添付は、それぞれ**別の設定**で見せるかを決める。
プロフィールを見せることと、年収や履歴書を渡すことは別の判断である
（[ADR 0030](../decisions/0030-profile-visibility.md)、
[ADR 0031](../decisions/0031-profile-documents.md)）。

## 4. 求人を探して応募する

| やりたいこと | 経路 |
| --- | --- |
| 求人を探す | `/ja/jobs` |
| 求人の詳細を見る | `/ja/jobs/:id` |
| 応募する | 求人の詳細から「この求人へ応募する」 |

応募の前に、**何が送られるか**が画面に出る。
送った内容はその時点のまま保存される。
後からプロフィールを変えても、送った応募の内容は変わらない
（[ADR 0034](../decisions/0034-job-application.md)）。

## 5. 応募のあとを追う

| やりたいこと | 経路 |
| --- | --- |
| 自分の応募を見る | `/ja/profile/applications` |
| 応募の詳細を見る | `/ja/profile/applications/:id` |
| 企業とやり取りする | 応募の詳細から「やり取りを見る」 |
| 通知を見る | `/ja/notifications` |
| メールの受け取りを設定する | `/ja/notification_settings/edit` |

**応募を取り消すと、同じ求人へは応募し直せない。**
取り消す前に画面で伝える（[ADR 0035](../decisions/0035-application-withdrawal.md)）。

企業側の評価・面接の予定・社内のメモは**見えない**。
これは意図的な設計である（[ADR 0039](../decisions/0039-application-review-and-assignment.md)）。

## 6. 自分のデータを持ち出す・消す

| やりたいこと | 経路 |
| --- | --- |
| 自分のデータをダウンロードする | `/ja/export` |
| プロフィールだけを消す | `/ja/profile` から「プロフィールを削除する」 |
| アカウントごと消す | `/ja/account_deletion` |

アカウントの削除にはパスワードの再入力が要る。
消す前に、ダウンロードへの導線が出る。

**組織の唯一の管理者になっている場合、アカウントを削除できない。**
先に別の管理者を立てる必要がある（[ADR 0033](../decisions/0033-account-deletion.md)）。
